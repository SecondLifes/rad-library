# Product — RAD Library AI Spec-Kit

Build a compact, stable and measured Delphi 13+ reusable library/component
set for Win32/Win64, VCL and FMX. Preserve the inherited correctness,
safety, SOLID, Clean Code, DUnitX and packaging disciplines.

The core is dependency-free. Optional integrations are isolated. Helper
units use `help.*`, public helper members begin with `_`, component classes
begin with `TRAD`, and examples never authorize invented APIs.

`AGENTS.md` is the complete behavioral contract.
